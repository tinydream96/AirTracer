# 🛰️ AirTracer 轨迹追踪系统 — 新手使用指南（Infi Tag 专属）

> **官方平台网址**：[https://airtracer.us/](https://airtracer.us/)  
> 无论是 iPhone、安卓手机还是电脑，直接在浏览器中打开上述网址即可使用。  
> 💡 **手机端小技巧**：在手机浏览器菜单中点击 **“添加到主屏幕”**，即可像原生 App 一样全屏打开，随时随地一键查看！

---

## 一、 账号注册与设备绑定

### 1. 打开官网并注册
* 打开 [https://airtracer.us/](https://airtracer.us/)，点击界面上的 **【注册】**。
* **用户名**：输入 3~20 位英文或数字（也可以点击输入框右侧的 🔄 刷新图标 随机生成）。
* **邮箱与密码**：输入常用邮箱并设置密码。
* 📌 *强烈建议：注册成功后点击 **【下载凭证】** 保存到手机或电脑，防止后续忘记密码。*

### 2. ⚠️ 最关键一步：联系管理员绑定设备
* 注册完成后，请将您注册的 **【用户名】** 或 **【邮箱】** 发送给管理员。
* 管理员在后台为您添加并绑定 Infi Tag 设备后，您**重新登录或刷新页面**，名下的设备就会自动出现在地图和列表中，无需任何繁琐配置！
* *注：新设备首次上线，若处于室内等弱信号环境，可能需要几分钟等待周围苹果设备路过并完成首次广播。*

---

## 二、 如何查看与切换设备？

登录进入地图主界面后：

### 📱 手机端 / 移动端用户
* 屏幕底部有一排胶囊状的设备卡片。
* **多设备切换**：若名下有多个 Infi Tag，按住底部卡片 **【左右滑动】** 即可浏览不同设备。
* **选中设备**：滑到想查看的设备后，**轻点一下该卡片**，地图会自动聚焦该设备的最新位置，并在屏幕右上角展开该设备的【详细信息卡片】。

### 💻 电脑端用户
* 屏幕左侧为设备列表栏，鼠标直接点击对应设备即可定位和选中。

---

## 三、 怎么查询与显示历史轨迹？

选中设备后，屏幕右上角会弹出该设备的 **【信息卡片】**。

卡片中间有一栏带有 **📅 日历图标** 的长条按钮（默认显示当前日期范围，如 `2026.08.17 → 2026.08.17`），系统会自动加载该时间段内的轨迹：

* 🟢🟡🔴 **速度着色轨迹线**：绿色代表慢速/停留，黄色代表中速移动，红色代表快速移动。
* ➡️ **流动方向箭头**：路线上有动态向前流动的白色小箭头，指示 Infi Tag 的实际移动方向。
* 📍 **点击轨迹点看详情**：点击路线上半透明的红色轨迹圆点，会弹出小窗显示**精确记录时间、当时速度、经纬度及定位精度**。

## 四、 怎么精准查询“指定时间范围”的轨迹？

如果您想查询特定某几天、或某天具体几点几分的轨迹：

1. **第一步：打开日历**  
   点击右上角信息卡片上的 **【📅 日期时间栏】**（显示日期区间的长条），弹出日历窗口。
2. **第二步：选择日期**  
   在日历上先点一下**开始日期**，再点一下**结束日期**（也可以直接点击底部的 “3天”、“7天”、“30天” 快速选择）。  
   🌟 **核心技巧（看小圆点）**：仔细看日历上的日期数字，**凡是下方带有“小圆点”的日期，才代表那天有采集到轨迹数据！** 没有小圆点表示该天无位置记录。
3. **第三步：精确到时分（选填）**  
   在弹窗顶部日期下方，有专门的时间下拉框（默认是 `00:00` 到 `23:59`），可手动调整为特定时间段（例如：`08:30` 至 `18:00`）。
4. **第四步：⚠️ 点击确认（关键步骤，千万别漏！）**  
   选好日期和时间后，**必须点击弹窗右下角蓝色的【确认】按钮！**  
   *(不要直接点右上角 ✕ 或点弹窗外空白处关闭，只有点击【确认】，系统才会向服务器拉取并绘制该时间段的轨迹)*

## 五、 常见疑惑：为什么选好了时间，地图上没有轨迹线？

如果发现没有出现轨迹线，请对照以下 **4 点原因** 逐一自查：

1. **❌ 忘了点击右下角的【确认】按钮 ⚠️**  
   *原因*：在日历选好后随手点了空白处关闭弹窗，查询条件未生效，地图仍停留在上一状态。
2. **⏸️ 该时间段内 Infi Tag 一直处于“静止状态”**  
   *原因*：Infi Tag 只有在发生位移时才会绘制连贯线条。若放在家中或车库一整天未动，系统只会记录原地停留点，不会生成长距离行车路线。
3. **⚪ 所选的日期在日历上“没有小圆点”**  
   *原因*：Infi Tag 基于苹果 FindMy 寻物网络。若设备长时间处于无人经过的极端偏僻盲区（周围无苹果设备路过协助中继），期间将不会产生位置数据。
4. **⏱️ 开始/结束时间倒置，或时间跨度过窄**  
   *原因*：如将开始时间误选为 17:00、结束时间选为 09:00（时间倒流）；或只选择了 1~2 分钟区间，而该区间内设备刚好未触发位置上报。

## 💡 实用操作小技巧

* **信息卡片不小心关掉了？**  
  若误点了右上角卡片的 ✕，直接点击地图右上角出现的 **【ℹ️ 信息图标】** 即可重新展开。
* **查看自己和设备的实时距离？**  
  点击屏幕右下角的 **📍【我的位置】** 按钮，地图会显示您当前所在位置，右上角卡片还会实时计算并显示设备 **“距您 xxx 米/公里”**。
* **切换高精度高清底图？**  
  点击屏幕右下角的 **🗺️ 图层按钮**，可自由切换为 **【高德地图】、【高德卫星】、【天地图】或【谷歌地图】**。
